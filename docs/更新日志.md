# 更新日志

这里记录已经进入 `main` 分支、对用户或二次开发者有可见影响的版本变化。项目尚未建立稳定版编号时，更新按日期归档。

## 2026-08-24

本次更新重点是让小满的表达方式可配置、生成文件能够真正交付给用户，并避免长时间工程任务被过短的通用超时提前终止。

### 新增功能

- **对话风格设置**：Dashboard 设置页新增自然、简洁、温和、专业、直率和活泼六种表达风格。选择结果保存在工作区，从下一条回复开始生效；它只改变表达方式，不改变模型能力、记忆、权限或事实标准。
- **生成文件自动交付**：当用户明确要求“把文件发给我”时，Agent 会从回复和工具结果中识别工作区内真实存在的生成文件，并把它们作为附件随最终回复交付。
- **Dashboard 文件下载**：生成文件会导入 Dashboard 管理的附件区，在聊天消息下方显示可下载文件；断线重连和会话持久化仍可保留附件记录。
- **QQ 文件发送**：QQBot 接入官方文件上传流程，支持摘要校验、分片上传、分片确认、服务端合并和最终文件消息发送；图片、视频、语音及普通文件会选择对应类型。

### 运行与交互改进

- 为同步 Shell 长任务增加独立的一小时预算，并将 SubAgent 和 Workflow 步骤预算分别调整为 65 分钟和 70 分钟，保持“工具内部 < 子执行 < Workflow”的嵌套关系。
- 普通模型调用和工具调用仍受较短预算保护，显式设置的更短 Shell 超时继续优先生效，自动转后台的 Shell 不会获得阻塞型长预算。
- QQ 回复上下文增加有效期和连续消息序号，避免过期消息 ID 或重复序号影响多段文本、文件回复。
- Dashboard 设置页增加响应式对话风格面板，聊天区增加 Assistant 附件下载样式，并移除侧边栏重复的运行状态卡片。

### 安全边界

- 自动交付只在用户明确索要文件时启用，只允许工作区内的普通文件，并限制单轮数量和文件体积。
- 已由 `message_push` 成功发送的文件不会重复交付；不存在、为空、越界或超限文件会被拒绝。
- Dashboard 通过不透明附件 ID 下载文件；QQ 群的主动文件推送继续遵守群级授权。

### 验证范围

- 对话风格的默认值、持久化、非法值回退和 Prompt 注入。
- Dashboard 文件导入、下载、WebSocket 交付和历史消息附件恢复。
- QQ 文件摘要、分片上传、消息序号、回复窗口与群权限。
- 长时间 Shell、SubAgent、Workflow 超时预算及短超时覆盖行为。
- 后端自动化测试、前端 TypeScript 检查、ESLint 和生产构建。
