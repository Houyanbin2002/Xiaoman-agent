# 项目文件说明

根目录只保留启动、安装、构建、测试以及 GitHub 展示必须或约定放在这里的文件。不要为了视觉整齐随意移动这些配置，否则对应工具可能无法自动发现它们。

## 启动与运行必需

| 文件 | 用途 | 是否可移动 |
|---|---|---|
| `main.py` | 小满的统一启动和命令行入口 | 不可移动 |
| `config.example.toml` | 初始化向导使用的安全配置模板 | 不可移动 |
| `requirements.txt` | Python 运行依赖 | 不建议移动 |
| `package.json`、`package-lock.json` | 前端依赖、检查和构建命令 | 不建议移动 |

`config.toml` 是本机运行配置，可能包含密钥。它必须留在本地且已被 Git 忽略，不能提交到公开仓库。

## 开发、测试和构建必需

| 文件 | 用途 |
|---|---|
| `requirements-dev.txt` | CI、测试和代码检查依赖 |
| `pyproject.toml` | Python 项目元数据以及 Ruff、Black 配置 |
| `pytest.ini` | Pytest 默认参数和测试标记 |
| `pyrightconfig.json`、`pyrightconfig.tests.json` | Python 源码与测试类型检查配置 |
| `eslint.config.js` | 前端 ESLint 配置 |
| `tsconfig.json` | TypeScript 类型检查配置 |
| `.github/workflows/ci.yml` | GitHub Actions 自动测试与前端构建 |
| `.gitignore`、`.dockerignore` | 排除本地数据、密钥、缓存和构建上下文垃圾 |

## GitHub 与开源项目入口

| 文件 | 用途 |
|---|---|
| `README.md` | GitHub 仓库首页，必须保留根目录和固定名称 |
| `LICENSE` | MIT 开源许可证，保留根目录便于 GitHub 识别 |
| `.github/CONTRIBUTING.md` | GitHub 自动识别的贡献指南 |
| `.github/SECURITY.md` | GitHub 自动识别的安全政策 |

## 已清理项目

- 空的 `.codex` 占位文件和仅含本机助手设置的 `.claude/`：没有运行时代码引用。
- `uv.lock`：只包含项目自身元数据，依赖实际由 `requirements*.txt` 管理，保留会让安装方式产生歧义。
- 旧审计基线：引用已废弃仓库、旧机器绝对路径和历史会话，已不对应当前源码。
- 重复评测稿和旧实现计划：未被代码引用，且已有更新后的正式文档或实际实现。
- 根目录 `xiaoman*.log`、Python/Pytest/Ruff 缓存：均为可重新生成的本地运行产物。

组件目录中的 `README.md`、`SKILL.md`、`ATTRIBUTION.md` 等不会统一搬走：它们属于对应组件、协议或许可证的一部分，文件名和相对位置具有实际含义。
