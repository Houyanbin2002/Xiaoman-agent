# 项目级代码审计（2026-08-24）

本次审计从真实入口反向追踪代码可达性，目标是在不改变产品能力的前提下，移除已退出运行链路的实现、测试和本地生成物，并把现行目录职责固定下来。

## 审计口径

- 服务入口：`main.py` 与 `bootstrap/` 的装配、启动和关闭链路。
- 对话入口：主 AgentLoop、SubAgent、Workflow、工具、记忆和主动协助链路。
- Web 入口：Dashboard API 注册和 `frontend/dashboard/src/main.tsx` React 入口。
- 保留条件：当前入口可达、属于稳定外部契约、或是现行 CI/评测框架的必要组成。
- 删除条件：入口不可达、没有稳定外部契约，且仅由旧实现测试或自身互相引用。

## 已移除

- 旧插件前端面板的动态编译、资源注入、SDK shim、设计组件和专属测试。当前插件仍可通过 `dashboard.py` 注册诊断 API，Dashboard 页面由主仓 React 应用统一构建。
- `agent/llm_json.py`、`agent/provider.py`、`bus/publisher.py`、`core/memory/events.py` 等完全不可达的兼容模块。
- 已无调用方的旧包装函数、过时字段断言和只验证已删除兼容层的测试。
- `docker/debug/` 下只服务于旧上下文/记忆方案的调试容器和场景。
- 未使用的 Python 与 Node 直接依赖；仍由现行依赖间接需要的包交给包管理器解析。
- 源码树中的历史评测结果、旧数据库、日志和工具缓存。可再生数据应写入 `~/.xiaoman/workspace` 或临时目录，不进入源码树。

## 现行边界

| 目录 | 当前职责 |
| --- | --- |
| `agent/` | 统一对话执行内核、上下文、工具、SubAgent 与 Workflow 执行 |
| `core/` | 记忆、个人数据、注意力和任务等领域契约与规则 |
| `bootstrap/` | 唯一组合根，负责依赖装配和服务生命周期 |
| `infra/` | 数据库、模型供应商、追踪等基础设施实现 |
| `plugins/` | 记忆/渠道适配器、生命周期扩展及诊断 API |
| `proactive_v2/` | 主动协助判断、调度与投递 |
| `eval/` | 当前 Rubric、LLM Judge、fixture 和真实 Agent 回归评测 |
| `frontend/dashboard/` | 唯一 Dashboard 前端源码 |
| `static/dashboard/` | 前端生产构建产物，由构建命令覆盖生成 |
| `tests/` | 现行能力、边界和回归测试，不保存历史方案墓碑测试 |

## 第二阶段：类型与运行边界治理

- 将主运行域与插件域统一纳入 `pyrightconfig.json`，把 37 个硬类型错误收敛为 0；不再允许插件目录游离在类型门禁之外。
- 修正 AgentLoop 的长期记忆装配：上下文构建器读取 `MemoryRuntime.profile`，Markdown Store 只承担近期活动与自我说明，不再被误当作完整长期记忆接口。
- 用最小 Protocol 固定 MCP 安装、Marketplace、模型供应商和 Markdown 支持接口，移除语义消费器中从未使用的会话读写回调。
- 对动态异步扩展点增加 `isawaitable` 判定，对数据库插入 ID、执行置信度、语义证据和插件元数据增加显式结构校验，避免 `object` 值直接进入核心域。
- CI 新增后端 Ruff 与 Pyright 门禁；今后提交同时验证后端测试、后端静态检查和前端构建。

## 后续质量债务

Pyright 的硬错误已经清零；仓库仍保留大量弱类型告警，主要来自外部 JSON、配置文件和数据库行对象。这些告警不阻断 CI，后续应按模块逐步用 TypedDict、Pydantic 模型和持久化 DTO 收窄，避免一次性注解重写影响运行逻辑。

- 将 TOML 解码入口统一收窄为 `dict[str, object]`，列表、整数和浮点数均通过显式转换函数进入配置模型；`agent/config.py` 的 Pyright 告警由 375 个降为 0。
- 将 Markdown 记忆存储实现迁入 `infra/persistence/`，`core/memory/` 只保留最小端口；把语义批次运行时、记忆插件装配合同和调度执行模型分别放回应用层、插件层和领域层。
- 抽出 Agent 执行/上下文端口和工具目录模型，解除 Prompt 组装器、工具搜索后端、Lifecycle、主循环之间的反向引用。
- 删除 `agent/core/runtime_support.py` 中与 `agent/looping/ports.py` 重复、且生产链路不再使用的 LLM/Memory DTO，测试统一验证现行主循环合同。
- 将记忆插件动态加载从通用 `bootstrap/wiring.py` 分离为 `bootstrap/memory_plugins.py`，避免局部装配为解析插件而反向依赖整个组合根。
- 生产代码静态依赖环由 4 组收敛为 0；新增自动化门禁，后续任何跨模块循环都会直接使测试失败。
