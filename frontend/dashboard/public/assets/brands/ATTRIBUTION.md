# Brand asset sources

Retrieved 2026-07-19 for identifying third-party integrations in Xiaoman.

- Notion: Simple Icons `notion` mark, based on Notion's black cube logo. Source: https://cdn.simpleicons.org/notion/000000
- Gmail: Google Gmail 2020 product mark. Source: https://upload.wikimedia.org/wikipedia/commons/7/7e/Gmail_icon_%282020%29.svg (original source credited to Google/gstatic).
- Obsidian: Simple Icons `obsidian` mark using Obsidian purple. Source: https://cdn.simpleicons.org/obsidian/7C3AED
- Microsoft: official four-pane Microsoft mark reproduced as four unmodified color squares according to Microsoft branding guidance: https://learn.microsoft.com/en-us/entra/identity-platform/howto-add-branding-in-apps
- GitHub: Simple Icons `github` mark based on GitHub's Invertocat. Source: https://cdn.simpleicons.org/github/181717
